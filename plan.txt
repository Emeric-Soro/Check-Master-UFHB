1. requirePermission() -- Eliminer 670 lignes
================================================================================

CONTEXTE :
Le bloc de verification de permission AJAX est copie 67 fois dans les
controleurs (ParametreController: 23x, GestionUtilisateurController: 7x,
GestionRhController: 5x, etc.). Chaque bloc fait ~10 lignes.

FICHIERS CONCERNES :
- app/controllers/ParametreController.php (23 occurrences)
- app/controllers/GestionUtilisateurController.php (7 occurrences)
- app/controllers/GestionRhController.php (5 occurrences)
- app/controllers/SauvegardeRestaurationController.php (4 occurrences)
- app/controllers/GestionEtudiantController.php (4 occurrences)
- 16 autres controleurs (24 occurrences)

SOLUTION :
Ajouter la fonction requirePermission() dans app/utils/permissions_helper.php

CODE A AJOUTER (a la fin de app/utils/permissions_helper.php) :

    /**
     * Verifie la permission et stoppe l'execution si refuse.
     * Gere automatiquement AJAX (403 JSON) vs classique (redirect).
     */
    function requirePermission(string $slug, string $action = 'voir'): void
    {
        $fn = match($action) {
            'creer'     => 'canCreate',
            'modifier'  => 'canEdit',
            'supprimer' => 'canDelete',
            default     => 'canView',
        };

        if ($fn($slug)) {
            return; // OK
        }

        $isAjax = !empty($_SERVER['HTTP_X_REQUESTED_WITH'])
            && strtolower((string)$_SERVER['HTTP_X_REQUESTED_WITH']) === 'xmlhttprequest';

        if ($isAjax) {
            http_response_code(403);
            header('Content-Type: application/json');
            echo json_encode([
                'success' => false,
                'message' => "Vous n'avez pas l'autorisation d'effectuer cette action."
            ]);
        } else {
            $_SESSION['error'] = "Vous n'avez pas l'autorisation d'effectuer cette action.";
            $_SESSION['error_type'] = 'permission_denied';
            header('Location: layout.php?page=access_denied');
        }
        exit;
    }

  AVANT (10 lignes, repete 67 fois) :

        if (!empty($_SERVER['HTTP_X_REQUESTED_WITH']) && strtolower((string) $_SERVER['HTTP_X_REQUESTED_WITH']) === 'xmlhttprequest') {

CONTEXTE :
Chaque operation CRUD dans ParametreService.php effectue des appels
redondants a auditLog->logCreation/logModification/logSuppression
avec le statut Succes/Erreur. 121 occurrences au total.

CODE A AJOUTER (methode dans ParametreService ou classe parente) :

    /**
     * Log une operation CRUD dans l'audit trail.
     */
    protected function logCrud(string $operation, int $userId, string $entity, bool $success): void
    {
        $status = $success ? 'Succes' : 'Erreur';
        match($operation) {
            'create' => $this->auditLog->logCreation($userId, $entity, $status),
            'update' => $this->auditLog->logModification($userId, $entity, $status),
            'delete' => $this->auditLog->logSuppression($userId, $entity, $status),
        };
    }

REMPLACEMENT :

  AVANT :
    $this->auditLog->logCreation($userId, 'Grade', 'Succes');

  AVANT :
    $this->auditLog->logSuppression($userId, 'Grade', 'Erreur');

  APRES :
    $this->logCrud('delete', $userId, 'Grade', false);

    /**
     * Telecharge un fichier XLSX.
     */
    function cm_xlsx_download(string $filename, array $headers, array $rows, ?string $title = null): void
    {
        while (ob_get_level()) { ob_end_clean(); }

        $spreadsheet = new \PhpOffice\PhpSpreadsheet\Spreadsheet();
        $sheet = $spreadsheet->getActiveSheet();
        $col = 1;

        if ($title) {
            $sheet->setCellValue(chr(64 + $col) . '1', $title);
            $sheet->mergeCells('A1:' . chr(64 + count($headers)) . '1');
            $startRow = 2;
        } else {
            $startRow = 1;
        }

        foreach ($headers as $h) {
            $sheet->setCellValue(chr(64 + $col) . $startRow, $h);
            $col++;
        }

        $rowNum = $startRow + 1;
        foreach ($rows as $row) {
            $col = 1;
            foreach ($row as $cell) {
                $sheet->setCellValue(chr(64 + $col) . $rowNum, $cell);
                $col++;
            }
            $rowNum++;
        }

        for ($i = 1; $i <= count($headers); $i++) {
            $sheet->getColumnDimension(chr(64 + $i))->setAutoSize(true);
        }

        header('Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
        header('Content-Disposition: attachment;filename="' . $filename . '.xlsx"');
        $writer = new \PhpOffice\PhpSpreadsheet\Writer\Xlsx($spreadsheet);
        $writer->save('php://output');
        exit;
    }

REMPLACEMENT :

    {

CODE A CREER : app/controllers/AbstractFicheController.php

    <?php

    use CheckMaster\Support\Database;

    abstract class AbstractFicheController
    {
        protected $service;

        abstract protected function getServiceClass(): string;
        abstract protected function getPermissionSlug(): string;
        abstract protected function getMethodName(): string;

        public function __construct()
        {
            $db = Database::getConnection();
            $class = $this->getServiceClass();
            $this->service = new $class($db);
        }

        public function index(): array
        {
            requirePermission($this->getPermissionSlug());
            $method = $this->getMethodName();
            return $this->service->$method($_GET, $_POST, $_SESSION['id_utilisateur'] ?? null);
        }
    }
