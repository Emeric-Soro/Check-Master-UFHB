I. ARCHITECTURE GÉNÉRALE
================================================================================

Framework : MVC PHP custom (pas de framework externe)
Routing   : $_GET['page'] → fichier route → contrôleur → vue
Entry     : public/indexCM.php (app) / public/page_connexion.php (login)
Landing   : index.php (page vitrine)

Structure :
├── app/
│   ├── config/         → database.php, email.php
│   ├── controllers/    → 37 contrôleurs
│   ├── Core/           → Router, Bootstrap, Csrf, Request, Response, Session
│   ├── middlewares/     → Middleware de sécurité/session
│   ├── models/         → 48 modèles
│   ├── Security/       → AuthorizationService, DbRateLimiter, LegacyActionResolver,
│   │                     RouteActionResolver, RoutePermissionService
│   └── utils/          → EmailService, ExcelImportService, FormattingUtils,
│                         permissions_helper, ReceiptUtils
├── ressources/
│   ├── routes/         → 30 fichiers de routes
│   └── views/          → ~60 fichiers de vues (organisés par module)
├── public/             → Assets publics, point d'entrée
├── src/                → input.css (entrée Tailwind)
└── vendor/             → Dépendances Composer
